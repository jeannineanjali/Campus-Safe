Campus Safe (SRM IST and SRM TRP) - no database version

Open index.html in Chrome or any phone browser. Nothing to install.
Data (tips, SafeWalk arrivals, check-ins) is saved in the browser with localStorage.
Settings has a "Clear saved data" button to reset.

To use on a phone: copy index.html to the phone, or host the file (GitHub Pages, Netlify)
and open the link. Contacts are sample data until verified by campus administration.
